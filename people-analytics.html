Cómo se construyó

Los datos se generan con Python y las cifras se calculan con SQL. Todo el código está en el repositorio y se puede volver a ejecutar:

  • datos/*.csv — datos de ejemplo (CSV)
  • sql/consultas.sql — consultas de cada cifra
  • python/generar_datos.py — genera los datos con una semilla fija
  • python/calcular.py — calcula las cifras con SQL (SQLite)
  • python/analisis.py — análisis adicional en Python
  • python/verificar.py — comprueba que este panel muestra las cifras del código
