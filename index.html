Resumen

Panel de una empresa de materiales de construcción de unos 1.000 colaboradores (plantas, centros de distribución y casa matriz), con datos sintéticos. Dos páginas de detalle:

Compensaciones

Bandas y compa-ratio, equidad salarial y brecha de género, presupuesto y gasto.

People Analytics

Dotación, rotación, rotación temprana y análisis de tendencia con Python.

Cómo se construyó

Los datos se generan con Python y las cifras se calculan con SQL. Todo el código está en el repositorio y se puede volver a ejecutar:

  • datos/*.csv — datos de ejemplo (CSV)
  • sql/consultas.sql — consultas de cada cifra
  • python/generar_datos.py — genera los datos con una semilla fija
  • python/calcular.py — calcula las cifras con SQL (SQLite)
  • python/analisis.py — análisis adicional en Python
  • python/verificar.py — comprueba que este panel muestra las cifras del código

Semilla de los datos: 1395547109.

Cifras verificadas con SQL (SQLite) y Python 3.12.10 el 2026-10-20.

La categoría de tamaño se define por la dotación de trabajadores dependientes (tramos del SII), no por las ventas anuales con que la Ley 20.416 define la micro, pequeña y mediana empresa. Los datos de este panel son sintéticos y no corresponden a una empresa real de ese sector y tamaño.
